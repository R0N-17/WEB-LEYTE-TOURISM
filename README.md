# Leyte Tourism Guide Web System

A web-based tourism guide system designed to help users explore selected tourist destinations in Leyte.

The system is being developed using Scrum, with features implemented progressively through separate Scrum/Jira branches.

## Project Status

### Sprint 1 — User Identity & Profile

Current Sprint 1 features:

- User Registration
- User Login
- User Logout
- Manage User Profile
- Save User Preferences
- Home Dashboard

Later features are currently marked as **Coming Soon** and will be developed in their respective sprints.
